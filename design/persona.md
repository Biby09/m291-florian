# Persona – Webapp de comparaison d'appareils photo

**Prénom**
Camille Dubois

**Âge**
26 ans

**Lieu**
Lausanne, Suisse

**Métier**
Photographe freelance / créatrice de contenu voyage

**Appareil principal**
Ordinateur

**Besoins fonctionnels**
- Comparer en détail les caractéristiques techniques (capteur, autofocus, stabilisation, plage ISO, vidéo, monture d'objectifs) entre plusieurs modèles
- Filtrer les appareils selon des critères techniques précis (taille de capteur, résolution, cadence de rafale, compatibilité objectifs)
- Accéder à des données chiffrées et des benchmarks pour appuyer ses choix

**Irritants majeurs**
- Fiches produits qui simplifient trop les caractéristiques techniques
- Impossible de comparer plus de deux appareils à la fois
- Manque de données chiffrées ou de benchmarks fiables
- Manque de transparence sur les vrais prix (frais cachés, disponibilité)

**Citation**
« Je veux les vraies specs techniques, avec des chiffres précis, pour comparer les appareils précisément. »
